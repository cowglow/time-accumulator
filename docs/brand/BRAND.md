# Time Accumulator brand pack

The mark is a square bracket frame around three colons (HH:MM:SS with the numbers left out).

| File | Use |
| --- | --- |
| `icon.svg` | Master mark, dark ground. Source of every PNG below. |
| `icon-light.svg` | Same mark on the light ground. |
| `favicon.svg`, `favicon.ico` | Tab-size version: heavier brackets and larger squares so it holds up at 16 and 32px. |
| `icon-192.png`, `icon-512.png` | Web app manifest, purpose `any`. |
| `icon-maskable-512.png` | Web app manifest, purpose `maskable`. The art already sits inside the safe zone. |
| `apple-touch-icon.png` | iOS home screen (180px, no transparency; iOS rounds the corners). |
| `social-preview.png` / `.svg` | GitHub social preview, 1280x640. Upload by hand in the repo's Settings > Social preview. |
| `manifest.webmanifest`, `head-snippet.html` | Manifest and the `<head>` tags that wire everything up. |

Colors (monochrome only):

| Token | Dark | Light |
| --- | --- | --- |
| Ground | `#15171a` | `#eceeef` |
| Mark | `#f5f5f3` | `#101214` |
| Secondary text | `#c7c9cc` | `#4b4f54` |
| Structure | `#797d82` | `#7a7e83` |

Type: IBM Plex Mono.
